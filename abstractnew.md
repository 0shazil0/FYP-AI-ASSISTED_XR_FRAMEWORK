# NeuroGuide XR: A Hierarchical Multi-Modal Framework for Context-Aware Spatial Assistance Across Physical Environments and Desktop Interfaces

**Abstract**—Real-time procedural task guidance in Augmented Reality (AR) requires balancing low-latency spatial interaction with high-level contextual reasoning. While Vision-Language Models (VLMs) offer rich scene understanding, their computational latency makes continuous execution impractical on mobile AR endpoints. Conversely, lightweight on-device detectors lack open-vocabulary flexibility and procedural reasoning capabilities. Additionally, existing AR guidance systems rarely bridge physical environment tasks and digital software workflows within a unified interface. We present NeuroGuide XR, an end-to-end client-server spatial assistance framework unifying physical scene coaching and digital desktop software guidance on a mobile AR platform. The system employs a hierarchical, event-gated perception architecture: for physical tasks, an inertial-temporal gating layer combining IMU sensor fusion and frame differencing suppresses redundant inferences, cascading to a lightweight detector for rapid localization, selective open-vocabulary grounding, and asynchronous VLM reasoning for multi-step coaching. For desktop workflows, a spatial virtual screen pipeline combines semantic lesson retrieval with a multi-tier element resolution hierarchy (Accessibility APIs, visual template matching, and screen parsing) and closed-loop structural similarity verification to confirm user step execution before advancing. The framework was implemented and demonstrated using a Unity AR client communicating via asynchronous WebSockets with a modular FastAPI backend. Functional evaluations across physical equipment guidance and interactive desktop applications demonstrate that hierarchical gating and multi-tier element resolution provide responsive spatial guidance and reliable step verification while avoiding continuous, compute-intensive VLM execution. This work offers a practical architectural design for dual-domain spatial computing assistants.

**Keywords**—Augmented Reality, Spatial Computing, Multimodal Interaction, Hierarchical Perception, Vision-Language Models, Context-Aware Systems, Human-Computer Interaction.
